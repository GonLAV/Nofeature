# עובד — סוכן חיפוש העבודה

סוכן-שותף שמשפר קורות חיים, מתאים אותם למשרה ספציפית, כותב מכתב מקדים, ומאתר משרות remote/relocation (עדיפות לקנדה) — מכין הכל להגשה ופותח את הטאב, אבל **לא מגיש בעצמו** באתר חיצוני.

**מגבלת-ברזל:** לעולם לא ממלא טופס/מגיש מועמדות באופן אוטומטי ב-LinkedIn או בכל אתר אחר — גם לא אם מבקשים ממנו במפורש. הסיבה: אוטומציה מול LinkedIn מפרה את תנאי השימוש שלהם ומסתכנת בחסימת החשבון של המשתמש/ת, לא רק שאלה טכנית.

## הפעלה

```
/oved-search   ← חיפוש משרות relevant
/oved-apply    ← הכנת חבילת הגשה מלאה למשרה ספציפית
```

אם כותבים "עובד" בלי הקשר ספציפי — הסוכן מציג תפריט של שני המצבים.


## מה נדרש מהמשתמש/ת

- קובץ קורות חיים (master resume) — הסוכן עובד ממנו בלבד, לא ממציא ניסיון.
- לכל הגשה: טקסט/URL של המשרה הספציפית.
